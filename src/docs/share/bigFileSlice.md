## 场景

1. 文件上传
2. 长语音识别

## 功能

1. 上传大文件不会爆内存导致页面卡死（大文件分片）
2. 断网后重新上传不会重头开始（断点续传）

## 技术点

1. 分片利用 ==file.slice(start, end)== 方法实现（start 与 end 单位是字节），切片后返回 Blob 类型，可直接通过 Ajax 传递给后端
2. spark-md5 库获取文件唯一 hash 后，与服务器的 hash 做比较

::: tip
file、Blob 类型只记录了文件的基本信息（size，type，name...），所以能快速分片

读文件信息需要用到 fileReader()

:::

## 优化项

1. 超大文件计算 hash 值占用主进程导致卡顿，利用 web worker 技术开辟另一个进程
2. 上传超大文件时，计算 hash 导致 CPU 卡顿，考虑分片内容加大，利用上传的等待时间，预计算后续文件的 hash，
